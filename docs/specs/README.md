# Feature specifications

Create one specification for each meaningful, independently deliverable
feature or behavioral change.

## Statuses

- `Draft`: under discussion; implementation should not begin.
- `Approved`: ready for implementation.
- `Implemented`: completed and verified.
- `Superseded`: replaced by another specification.
