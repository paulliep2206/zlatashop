Start with `.agents/skills/payload/SKILL.md` for a quick reference, then see `.agents/skills/payload/reference/` for detailed docs.

## Specification workflow

Feature specifications live in `docs/specs/`.

For meaningful feature work:

1. Read the relevant approved specification before implementation.
2. Treat its acceptance criteria, constraints, and out-of-scope section as binding.
3. If requirements are ambiguous or contradictory, stop and raise them before implementation.
4. Map completed work and verification evidence to each acceptance criterion.
5. Do not modify an approved specification merely to make the implementation conform.
